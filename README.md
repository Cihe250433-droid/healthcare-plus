# Healthcare Plus

Healthcare Plus is a full-stack healthcare management web application built for Assessment 3.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## Features

- User registration and login
- Patient management
- Appointment management
- Subscription and billing section
- Dashboard overview
- Secure backend API
- MongoDB database connection
